# Continuum
Stay in flow, even with breaks. Remembers your working tabs and brings you back when you drift.

# What it does
Track any tab as a task (manual) or auto-track domains like github.com
Starts a timer when you leave the tab
After 5/10/30 min, shows a popup + notification: "Still working on this?"
Return to tab or mark Finished (silences domain for 1 hour)

# Install
Chrome / Edge / Brave (Chrome-based browsers):

chrome://extensions → Developer mode ON
Load unpacked → select this folder

# How to use
Open a working tab
Click the Continuum icon → Track this tab
Switch away
Get nudged back

Click the settings icon for options and settings.
Set default domains from the options page.

# Privacy
No data collected. Everything stays in local storage.

Built with Manifest V3.
